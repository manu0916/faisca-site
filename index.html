DO DOWNLOAD À PRIMEIRA DESCOBERTA

Instalar é simples.
A gente te acompanha.

No Android, o APK é o arquivo de instalação do aplicativo. A versão para Windows usa um instalador EXE tradicional.

  1. 01

    Escolha seu aparelho

    Use o botão Windows no computador ou Android no celular e tablet.

  2. 02

    Baixe o aplicativo

    Aguarde o download completo do EXE ou APK antes de abrir o arquivo.

  3. 03

    Abra o instalador

    No Windows, execute o EXE. No Android, abra o APK pela pasta Downloads.

  4. 04

    Confirme a instalação

    Siga as instruções do sistema para instalar ou atualizar o Faísca.

  5. 05

    Autorize, se solicitado

    No Android, permita a instalação para o navegador ou gerenciador de arquivos usado.

  6. 06

    Pronto para descobrir

    Abra o Faísca e continue suas trilhas, salas e atividades.

ⓘ Para atualizar sem perder o progresso, instale a nova versão sobre a atual. Não desinstale antes; exporte uma cópia do progresso por segurança.

O que é o Faísca?

É um aplicativo educativo de programação, com explicações em português, exemplos, exercícios e revisão. A proposta é aproximar o aprendizado da prática, uma descoberta de cada vez.

Para quem o aplicativo foi feito?

Para estudantes e pessoas que querem aprender programação. Professores também podem usar as trilhas como apoio às aulas. Todos usam o mesmo aplicativo.

Preciso ter experiência em programação?

Não. Você pode começar pelos fundamentos, ler os exemplos e praticar no seu ritmo. As orientações dos exercícios ajudam a entender o que precisa de atenção.

Quais linguagens estão disponíveis?

As trilhas são Python, JavaScript, HTML & CSS, SQL, Java, Kotlin, TypeScript, C, C++, C#, PHP e Swift. Veja todas as trilhas.

O aplicativo funciona offline?

As lições incluídas no aplicativo podem ser estudadas sem conexão, com o progresso salvo no aparelho. Recursos de conta e sincronização precisam de internet.

Preciso criar uma conta para baixar?

Não. O download pelo site não exige cadastro. Dentro do aplicativo, você também pode começar a estudar sem criar uma conta.

Para que serve a conta dentro do aplicativo?

A conta é opcional e sincroniza seu progresso entre celular, tablet e computador. A sincronização depende de conexão, do serviço de conta disponível e do aplicativo aberto. Antes de trocar de dispositivo, confira o estado “Sincronizado” e exporte também uma cópia do progresso.

Como instalo o APK?

Baixe o arquivo no Android, espere o download terminar e abra o APK. Se o sistema pedir, autorize a instalação para a origem utilizada e conclua. Confira o passo a passo completo.

Como atualizo sem perder meu progresso?

Primeiro, exporte o progresso pelo perfil e guarde a cópia em um lugar seguro. Se você usa conta, confira também se a sincronização terminou. Depois, baixe a nova versão e instale sobre a atual.

A atualização precisa ser compatível, ter o mesmo identificador de aplicativo e usar a mesma chave de assinatura da versão instalada. Se houver conflito, preserve a cópia do progresso antes de qualquer reinstalação. Não desinstale o aplicativo sem esse cuidado.

Posso utilizar o Faísca como apoio às aulas?

Sim. Professores podem criar salas, acompanhar estudantes e lançar trabalhos, projetos ou lições de casa com prazo. Nas lições de casa, também é possível indicar até qual lição a turma deve fazer e adicionar uma descrição opcional.

Existe versão para iPhone ou computador?

Há um instalador EXE para Windows e uma versão web para computador. No iPhone e iPad, a versão web pode ser aberta pelo navegador; o APK é exclusivo para Android.
